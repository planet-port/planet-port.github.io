只留一个入口，就意味着每次换环境都重新配置。Planet Port 把所有入口留在手边，切换只是一条命令。

多 Planet 并存。官方与私有 Planet 同时登记，互不覆盖，各自记住自己的网络与配置。网络清单跟着各自的 Planet 走，删除一份不影响其余。

一键切换。eval $(planet-port use company) 即刻生效，终端、路由、DNS 同步跟随，无需重装。官方 Planet 始终在列，一条命令就能切回。

多网络同连。App 在单隧道内让多个网络并行在线，切换 Planet 不打断已连接的网络；桌面端每网络一张虚拟网卡，由系统原生承载。

掌控路由与 DNS。routeViaZeroTier 与 dnsMode 逐网络设定，流量走哪条路、域名谁来解析，由你决定。dnsMode=none 时，解析完全交回系统处理。

切换 Planet

登记 Planet。

planet-port planet add ./company.planet --name company 收进列表，官方 Planet 原样保留。URL 也能直接登记，别名用 --name 指定。

切换入口。

eval $(planet-port use company) 之后所有操作指向这份 Planet。官方 Planet 始终在列，切回也是一条命令。

加入网络。

planet-port join 8056c2e21c000001 连上目标网络，多个可同时在线。网络与 peers 状态在 CLI 和 App 里一致。

常见问题

Planet 是什么？

ZeroTier 的根服务器文件。官方客户端只认一份，Planet Port 把多份收进一个列表。

和官方客户端有什么区别？

多份 Planet 并存、随时切换，各自的网络清单跟着各自的 Planet 走。

切换后，原有网络会断吗？

不会。多个网络同连，不同 Planet 下的网络并行在线，切换不打断连接。

DNS 可以完全不交给 ZeroTier 吗？

可以。dnsMode=none 时解析完全交回系统处理；另有 network（用网络下发的解析）与 custom（自指定服务器）两档。

Moon 是什么？

ZeroTier 的中继根服务器。orbit 加入、deorbit 退出，.moon 是它的文件。

和 ZeroTier, Inc. 是什么关系？

没有关系。Planet Port 是社区驱动的非官方客户端，与 ZeroTier, Inc. 无隶属关系。

更多细节见 GitHub 仓库的 README 与 issues。
