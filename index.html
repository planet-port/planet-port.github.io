多颗 Planet，

Planet Port 是跨平台 ZeroTier 客户端：多 Planet 并存、一键切换，路由与 DNS 全程可控，移动端与桌面端同行。

获取 Planet Port 查看路线图

已发布：iOS · Android · macOS / Linux / Windows CLI。GUI 与鸿蒙在路上。

一份列表，
装下所有 Planet。

官方 Planet 与 私有根服务器 同时收进一份列表，切换只是 一条命令，多个网络 同时在线，路由与 DNS 听你指挥。

多 Planet 并存。

官方与私有 Planet 同时登记，互不覆盖。

开 → 3 份 Planet 在列

official 为内置保留，私有 planet 文件跟随项目目录，use 只改指向、不动文件。

一键切换。

eval $(planet-port use company) 全局生效。

开 → 当前：company

写入当前 Planet 指向，CLI 与 GUI 读同一份配置；join / leave 都作用于当前 Planet。

多网络同连。

不同 Planet 下的网络并行在线，切换互不打断。

开 → 5 个网络在线

App 在单隧道内并行承载多网络；桌面端每网络一张虚拟网卡，由系统原生承载。join 后可分别 leave，网络 id 来自 ZeroTier Central。

路由掌控。

routeViaZeroTier 逐网络设定流量走向。

开 → 流量走 ZeroTier

routeViaZeroTier 开 = 流量走 ZeroTier，关 = 走本地默认路由；按网络设定，互不影响。

DNS 掌控。

dnsMode 三档：none / network / custom。

开 → 解析交给网络

none 不接管 / network 走网络解析 / custom 自定义服务器；对系统 DNS 的改动随开关回滚。

添加

把 Planet 收进列表，官方 Planet 原样保留。

--name 起别名，planet 文件原地不动；同名会提示而不是覆盖。

planet-port planet add ./company.planet --name company

切换

一条命令全局生效，之后的操作都指向这份 Planet。

切换不改网络成员身份，只换根服务器指向；再次 use 即切回。

eval $(planet-port use company)

联网

join 多个网络，并行在线。

桌面端每网络一张虚拟网卡，系统原生承载；join 后等待管理员授权，leave 随时可退。

planet-port join 8056c2e21c000001

掌控

routeViaZeroTier 定流量走向，dnsMode 定解析归属。

两项都按网络粒度设置：同一台机器上，办公网走 ZeroTier、其他网络照常。
