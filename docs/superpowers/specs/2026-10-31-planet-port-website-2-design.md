# Planet Port 品牌网站 v2 设计文档

日期：2026-10-31
状态：已与用户确认设计，待实现

## 背景与目标

Planet Port 是跨平台 ZeroTier 客户端（iOS / Android / 鸿蒙 / macOS CLI + 规划中 GUI），核心能力为多 Planet 并存管理、多网络同连、默认路由与 DNS 掌控、Moon 支持。已有 v1 官网（`../planet-port-website`，原生 HTML/CSS/JS + Vite）。

本项目 `planet-port-website-2` 为全新单页介绍网站，出**现代**与**未来**两套独立风格方案，供最终二选一。文案与章节结构全新撰写（不复用 v1 原句），仅复用 logo 与截图等静态素材。

## 总体架构

```
planet-port-website-2/
├── index.html          # 极简入口：左右分屏风格选择
├── modern.html         # 现代风单页（完全独立）
├── future.html         # 未来风单页（完全独立）
├── styles/
│   ├── entry.css       # 入口页样式
│   ├── modern.css      # 现代风全部样式
│   └── future.css      # 未来风全部样式
├── scripts/
│   ├── entry.js
│   ├── modern.js
│   └── future.js
├── public/assets/      # 从 v1 拷贝的 logo 与真实截图（不引外部 CDN）
└── vite.config.js
```

- 三页各自持有独立 HTML/CSS/JS，互不共享代码，每套可原样摘出独立上线
- 两套风格页右下角固定风格切换按钮（modern ⇄ future）；入口页不放
- 无线上字体/图片 CDN，离线可完整呈现
- 页脚保留"非官方客户端，与 ZeroTier, Inc. 无隶属关系"声明

## 内容结构

- 事实层两套一致：功能名称与描述用真实原词；未发布功能如实标注，不写成已上线

## 视觉与交互

### modern.html —— 克制精致

- 配色：浅色基底（约 `#FAFAFA`）+ 深色首屏对比；单一品牌主色（蓝/青系）+ 中性灰阶
- 排版：无衬线大标题、紧凑字距、清晰网格；数字/命令用等宽字体
- 组件：卡片圆角 + 细边框 + 极浅投影
- 动效：滚动淡入、hover 微抬升，≤200ms，`prefers-reduced-motion` 降级
- 截图：设备外框（手机/终端窗口）内嵌真实截图，横向滚动浏览

### future.html —— 沉浸炫技

- 配色：深空底（约 `#050508`）+ 霓虹青/品红点缀 + 玻璃拟态卡片
- 视觉母题：行星轨道——首屏轨道动画、章节分隔轨道弧线、平台矩阵星图网格
- 动效：canvas 星空粒子背景（可降级）、滚动视差、HUD 扫描线细节
- 组件：玻璃卡片 + 霓虹描边 + 等宽终端式点缀（章节编号如 `01 / 概念`）
- 截图：全息投影式外框，微悬浮动画

### 共同约束

- 响应式：桌面/平板/手机断点；移动端导航汉堡菜单
- 系统字体栈（中文 PingFang / 微软雅黑退化），零外部请求
- 截图素材从 v1 `public/assets/` 拷贝复用；v1 无桌面端截图则用代码块样式呈现 CLI 命令，不伪造截图

## 事实基准

- 移动端：iOS / Android / 鸿蒙 App
- 桌面端：macOS CLI ✅ 已发布（daemon 常驻架构）、macOS GUI 📐 规划中、Linux 🚧 适配中、Windows 📐 规划中
- 仓库入口指向 `github.com/planet-port` 组织下对应仓库
- Roadmap 内容从各仓库 README 现状整理，不虚构条目

## 工程细节

- 技术栈：原生 HTML/CSS/JS + Vite（仅 devDependency，多页配置 `rollupOptions.input` 三入口）
- 无测试用例、无 UI 框架、无 npm 运行时依赖
- 构建产物可直接部署任意静态托管

## 验收标准

1. `npm run dev` 下三页正常浏览，所有交互（导航、风格切换、滚动动效、移动端菜单）工作正常
2. 断网状态下三页完整呈现
3. `npm run build` 产物可离线打开运行
4. 功能描述与各仓库 README 无出入，未发布功能未写成已上线
