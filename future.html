// PLANET PORT — MULTI-PLANET CLIENT

私有星域，
随身跃迁。

每颗 Planet 都是一片星域。Planet Port 让它们同机并存—— 多 Planet 管理、多网络同连、路由与 DNS 全程掌控。

进入星图 GITHUB
01 / 星域

每颗 Planet，一片星域

ZeroTier 网络由 Planet 根服务器指引方向。官方只有一颗；你自建的每一颗， 都是一片私有星域。Planet Port 让多份 Planet 同机并存—— 切换 Planet 只是换一条航线，你的网络与配置原样保留。

02 / 能力舱段

核心能力

CAP-01

多 Planet 并存

官方与多份私有 Planet 同机共存，别名管理、一键启停，互不干扰。

CAP-02

多网络同连

每 Planet 独立身份，join / leave 自如，网络与 peers 跨 Planet 聚合查询。

CAP-03

路由与 DNS 掌控

默认路由开关、dnsMode 三种模式，陈述式配置，脚本友好。

CAP-04

Moon 支持

orbit / deorbit、导入 .moon 文件，中继节点一样纳入管理。

03 / 两个座舱

同一件事，两种方式

移动端与桌面端做的是同一件事——行星管理，只是座舱不同。

掌上终端 · MOBILE

移动端 App

iOS / Android / 鸿蒙原生 App。行星管理、网络开关、peers 状态，指尖完成。

舰桥主控 · DESKTOP

桌面端 CLI

macOS CLI 已发布：特权 daemon 持有核心与虚拟网卡，CLI 只是薄客户端—— GUI 不开、隧道照跑。GUI 与 Linux / Windows 在路上。 

$ planet-port add ./my.planet --name company
$ eval $(planet-port use company)
$ planet-port join 8056c2e21c000001
04 / 跃迁序列

三步接入

  1. SEQ-01

    导入 Planet

    本地文件或 URL 导入，起一个好记的别名。

  2. SEQ-02

    加入网络

    输入 Network ID，join 并随时 leave。

  3. SEQ-03

    一键切换

    在任意 Planet 之间即时切换，无需重启服务。
